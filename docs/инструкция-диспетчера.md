# Инструкция для диспетчера и руководителя

## Новая заявка

«Новая заявка» → город, объект (можно вписать новый — он добавится в справочник), адрес (подставится из справочника), описание. Приоритет, исполнитель, плановая дата, контакт, вложения (до 10 файлов по 20 МБ) и примечание — по желанию. Если исполнитель выбран, заявка сразу «Назначена». Если по объекту уже есть открытая заявка, система предупредит.

## Список заявок

- По умолчанию показаны открытые: аварийные сверху, дальше по плановой дате. Просроченные выделены красным.
- Над списком — счётчики по статусам (с учётом фильтров), нажатие фильтрует.
- Поиск одной строкой: номер, объект, текст задачи, IP устройства из отчётов.
- «Фильтры»: статус, город, объект, исполнитель, приоритет, даты создания и выезда, «Только мои». Нажатие на заголовок столбца сортирует.
- «Выгрузить в Excel» выгружает текущую выборку.

## Карточка заявки

- Кнопки: «Назначить» (исполнитель, дата, приоритет), «Изменить статус» / «Переоткрыть» (закрытую заявку можно вернуть в «Повторный выезд»), «Отменить» (причина обязательна), «Скачать отчёт (PDF)».
- «Завершение работ» — все отчёты: время, карта с точками приезда и завершения, фото (нажмите для просмотра на весь экран), видео, таблица устройств со строкой замены «старый IP → новый IP».
- Отчёт с пометкой «На проверку» — время на телефоне расходится с серверным или отметка далеко от объекта.
- Руководитель может оставить комментарий к отчёту. Сам отчёт не редактируется.

## Справочники (`Справочники`)

- **Объекты** (диспетчер и руководитель): поиск, правка, координаты (для контроля расстояния), загрузка из Excel. Записи не удаляются — снимите «Активен».
- **Города**: при вводе названия код предлагается автоматически (Семей → SEM). Код меняется, только пока по городу нет заявок.
- **Сотрудники** (руководитель): почта, ФИО, роль, телефон, загрузка из Excel. Уволенного отключите — войти он не сможет, отчёты сохранятся.
- **Устройства и приоритеты** (руководитель): типы, действия (смысл действия определяет изменения реестра), приоритеты, порог расстояния.
